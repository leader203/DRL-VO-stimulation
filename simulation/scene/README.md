# 场景组合与物理

ROS 2 会话将源场景、用户覆盖层和机器人组合到会话私有 USD。实际物理地图、人物创建及门协作由 [ROS 2 导航](../docs/ros2_navigation.md) 的会话负责。

| 文件 | 职责 |
|---|---|
| `composition.py` | 临时 USD 层、机器人初始位姿、单位与上轴校验 |
| `physics.py` | 物理步频、求解器设置及机器人刚体验证 |
| `namespaces.py` | 查找可编辑的运行时父节点并分配路径 |

声明单位的覆盖层与机器人资产须与环境的长度、质量单位和上轴一致。未声明指标的覆盖层按目标舞台坐标解释。组合不修改源 USD；转换规则见[单位说明](../docs/units.md)。

已有的活动 PhysicsScene 计数包含实例代理。多个活动场景会被拒绝。显式物理覆盖要求现有场景可编辑。门元数据和几何覆盖层由各场景维护，ROS 门适配器按描述符协调实测开度和通行。
