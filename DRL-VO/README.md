# 四行人最终模型演示

运行 `./run.sh`。模型来自本轮有人组 480000 步 / 937 次更新，权重已复制固定；0.5 米前瞻，四名物理行人，冻结模型 eval 模式、确定性均值，不更新策略。

在“NewMetro · DRL 交互选点”窗口左键选点，点击“开始导航”。结束请点“结束演示”。关闭选点窗口标题栏只会隐藏窗口。

每次开始一个新目标，首个 subgoal 发布后，先保持线速度指令为 0，按最短转角顺时针或逆时针原地对齐。对齐目标固定在世界坐标中，最大角速度 0.8 rad/s；朝向误差进入 5° 内、实测角速度降至 0.1 rad/s 内并保持 0.15 秒后，下一控制步才开始 DRL-VO 推理和导航。后续 subgoal 正常交给模型。参数记录在每次运行的 ROBOT_CONTROL.json / first_subgoal_alignment 中，对齐过程保存为 INITIAL_ALIGNMENT_EVENTS.jsonl；此期间不生成策略输入、不调用模型、不累计策略动作步数。

训练预算已经完成，演示结束后不会重启训练。最多 3600 秒墙钟或 18000 个物理控制步；碰撞代理、超时等终止标准沿用演示入口，未放宽。

PROVENANCE.json 保存模型来源和哈希；runs/click_* 保存实际日志。演示表现不等于训练期随机策略统计或独立安全评估。
